Managed effects

An effect can be attached to an existing element. This remains an ordinary button with its native pointer and keyboard behavior.

No action yet.

Removing the effect releases its rendering resources and listeners. The action button remains functional. Reduced motion suppresses the ripple.

import { mountEffect } from '../dist/frontend-toolkit.esm.js';

const effect = mountEffect(button, {
  effect: 'highlight', preset: 'ripple', activation: 'click'
});

// During component teardown:
effect.destroy();
