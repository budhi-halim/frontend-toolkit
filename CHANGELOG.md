# Changelog

## 1.0.0

First versioned repository assembly, based on the approved development previews.

- Nineteen renderer families with declarative elements, managed mounting, and low-level imports.
- Selective loading, shared scheduling, bounded buffers, adaptive quality, and effect-specific motion policy.
- A public, responsive demo with explicit Full/Reduced motion comparison and a separate advanced lab.
- Falling snow, autumn leaves, petals, and seeds; corrected preview centering and status layouts.
- Preserved glass map and approved rendering implementations.
- MIT project license, retained third-party notices, generated option reference, examples, and reproducible tests.

The `2.0.0-preview.*` strings were development snapshot labels, not a public stable release series. This repository uses `1.0.0` for the first intended stable release. No GitHub or npm release has been created by assembling these files.
